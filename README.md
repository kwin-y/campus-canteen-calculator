-- HOW TO RUN
1. Make sure index.html and script.js are in the same folder.
2. Open index.html in a web browser (double-click the file, or right click->Open with->your browser).
3. Follow the prompt dialogs:
	- Enter your name
	- Enter category(student/staff/guest)
	- Enter quantities for Rice Meal, Chicken Meal, and Juice
4. The receipt appears as an alert popup and is also logged to the browser console.
5. To view the console output, open Developer Tools and select Console.
6. To run again, refresh the page.
